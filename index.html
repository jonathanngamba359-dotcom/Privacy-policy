Politique de Confidentialité de JoSmart Chat

Dernière mise à jour :17 Mars 2026

1. Données collectées

Nous collectons les données suivantes :

  • Informations de compte : nom, adresse email, photo de profil, biographie
  • Messages : contenu des conversations (texte, images, audio)
  • Statuts et publications : contenu que vous partagez publiquement
  • Données techniques : type d'appareil, version de l'OS
  • Données d'utilisation : fréquence d'utilisation, interactions, préférences

2. Utilisation des données

Vos données sont utilisées pour :

  • Fournir et améliorer nos services de messagerie
  • Permettre la communication entre utilisateurs
  • Traduire automatiquement les messages (via IA)
  • Fournir l'assistant IA conversationnel
  • Personnaliser votre fil d'actualité
  • Assurer la sécurité et prévenir les abus
  • Envoyer des notifications relatives au service

3. Partage des données

Nous ne vendons JAMAIS vos données personnelles.

Vos données peuvent être partagées avec :

  • Les autres utilisateurs (informations de profil publiques)
  • Nos prestataires techniques (hébergement, IA) sous contrat de confidentialité
  • Les autorités si requis par la loi

4. Stockage et sécurité

  • Vos données sont stockées sur des serveurs sécurisés
  • Les mots de passe sont chiffrés (hachage bcrypt)
  • L'accès aux données est protégé par authentification JWT
  • Nous utilisons le protocole HTTPS pour toutes les communications

5. Vos droits

Vous avez le droit de :

  • Accéder à vos données personnelles
  • Modifier vos informations de profil
  • Supprimer votre compte et vos données
  • Bloquer d'autres utilisateurs
  • Désactiver les notifications

Pour exercer ces droits, contactez-nous à : contactjosmart1@gmail.com

6. Protection des mineurs

JoSmart Chat est destiné aux personnes de 13 ans et plus. Nous ne collectons pas sciemment de données auprès d'enfants de moins de 13 ans.

7. Modifications

Nous pouvons mettre à jour cette politique. Les modifications seront notifiées dans l'application.

8. Contact

Pour toute question : contactjosmart1@gmail.com

Suppression de compte et des données

Les utilisateurs ont le droit de demander la suppression de leur compte et de toutes les données personnelles associées.

Pour effectuer une demande de suppression de compte, veuillez nous contacter à l’adresse suivante : contactjosma1@gmail.com

Nous traiterons votre demande dans un délai de 7 jours maximum.

Une fois la demande traitée, toutes les données associées au compte seront définitivement supprimées de nos systèmes, sauf si leur conservation est requise par la loi.
